# Assets

## Icons

For a production build, add the following icon files:
- `icon-16.png` (16x16 pixels)
- `icon-48.png` (48x48 pixels)
- `icon-128.png` (128x128 pixels)

You can create these icons using:
- Figma or Canva for design
- Online icon generators
- The 💬 or ✨ emoji as a base

Recommended style: Gradient purple/indigo background with a chat bubble or sparkle icon.

## For MVP Testing

Create simple placeholder icons or comment out the icon references in manifest.json temporarily.

### 2. 💬 [Charm AI](./projects/charm-ai)
**AI-Powered Dating Conversation Assistant**

Chrome extension that learns your messaging style and helps you maintain engaging conversations across dating apps and social platforms.

- **Status:** In Development 🚧
- **Tech:** Chrome Extension, TypeScript, OpenAI API
- **Platforms:** WhatsApp Web, Instagram, Tinder, Bumble, Hinge
- **Features:**
  - Message style learning from your chat history
  - Context-aware response suggestions
  - Auto-reply mode for maintaining conversations
  - Personality matching and flirting assistant

[View Project →](./projects/charm-ai)

## 🚀 Quick Start

Each project has its own README with setup instructions. Navigate to the project folder to get started.

```bash
# ScoreKeepr
cd projects/scorekeepr
npm install && npm run dev

# Charm AI
cd projects/charm-ai
npm install && npm run build
```
